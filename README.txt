==================================================
CALMA Coworking Space & Cafe - Website Files
مجلد ملفات الموقع الجاهزة للنشر والرفع المباشر
==================================================

هذا المجلد يحتوي حصرياً على الملفات البرمجية والصور الأساسية
اللازمة لرفع الموقع على أي استضافة (Hosting / cPanel / Netlify / Vercel / GitHub Pages).

محتويات المجلد:
1. index.html          (الصفحة الرئيسية للموقع)
2. css/style.css       (ملف التنسيقات والتصميم بالكامل)
3. js/main.js          (ملف البرمجة والتفاعل والمنيو والواتساب)
4. images/             (شعار المكان وصور المعرض الحقيقية)
5. images/drinks/      (23 صورة حقيقية لكافة مشروبات وأصناف المنيو)

طريقة الرفع:
قم برفع محتويات هذا المجلد مباشرة إلى مجلد public_html في الاستضافة
أو سحب وإفلات (Drag & Drop) في Netlify / Vercel ليعمل الموقع فوراً.
